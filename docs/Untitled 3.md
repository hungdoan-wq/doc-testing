**## Jan 28, 2026**  
**### New feature**  
We've revamped the ****Plans**** module to give you greater flexibility and control over release management.  
- ****Dual view options**** - Switch between the new Releases view and the existing Timeline view to manage your work the way you prefer  
- ****Releases view**** - Get a structured, table-based overview of all your releases with searchable, filterable access to key release details  
- ****Manual release creation**** - Create and manage releases directly within Katalon without needing to switch to your ALM tool

**#### Enhancement**  
The ****Run view**** in the Executions module has been completely redesigned with a cleaner, more intuitive interface for better test run visibility and management.  
- ****Richer execution details**** - View execution metadata including type, executor, environment, and test case associations at a glance  
- ****Advanced filtering**** - Filter executions by date range, source, type, status, and executor with additional filter options available
