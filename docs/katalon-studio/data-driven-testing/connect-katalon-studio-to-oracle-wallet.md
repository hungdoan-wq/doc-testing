<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">Oracle Wallet is a method to manage database credentials  across multiple domains. Connecting to  Oracle databases using a Cloud Wallet is a secure method that leverages Oracle security features for accessing authentication and user credentials. </p><p className="p">To incorporate Oracle Wallet for data-driven testing with Katalon Studio, do as follows:</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <a className="xref j-external-link" href="https://www.oracle.com/se/database/technologies/appdev/jdbc-downloads.html" target="_blank">JDBC and UCP Downloads page | Oracle Sverige</a> and download the Oracle JDBC Driver and Universal Connection Pool (UCP) <code className="ph codeph">.jar</code> files that are compatible with your Katalon Studio version:</span><div className="itemgroup info"><ul className="ul"><li className="li">if you use version 9.0.0 onwards, download <code className="ph codeph">orajdbc11.jar</code> and <code className="ph codeph">ucp11.jar</code></li><li className="li">if you use version 8.x, download <code className="ph codeph">orajdbc8.jar</code> and <code className="ph codeph">ucp.jar</code></li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Add them to <span className="ph uicontrol">Library Management</span> and exclude the current Oracle JDBC library. For detailed instructions, see <a className="xref" href="/katalon-studio/manage-projects/project-settings/library-management-in-katalon-studio">Add and exclude libraries</a>.</span><div className="itemgroup info"><img className="image" width={600} src={useBaseUrl("/4ec9cea3-e887-4e59-8463-5831ebd09529/ks-oracle-cloud-add-jdbc11.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Open the <code className="ph codeph">katalon.ini</code> file in a text editor. To locate the file:</span><div className="itemgroup info"><ul className="ul"><li className="li">On macOS: Right-click on the Katalon Studio application and choose <span className="ph uicontrol">Show Package Contents</span>.           Then, go to <span className="ph uicontrol">Contents</span> &gt; <span className="ph uicontrol">Eclipse</span> &gt; <span className="ph uicontrol">katalonc.ini</span>. The file path should be: <code className="ph codeph">/Applications/Katalon Studio Arm64/Contents/Eclipse/katalon.ini</code></li><li className="li">On Windows: Open the folder that contains Katalon Studio application. For example: <code className="ph codeph">C:\Users\&lt;username&gt;\Downloads\Katalon_Studio_Windows_64-8.6.9\katalon.ini</code></li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">In the <code className="ph codeph">katalon.ini</code> file, do the following:</span><ol type="a" className="ol substeps"><li className="li substep"><span className="ph cmd">Input the Oracle TCPS connection java options in the <code className="ph codeph">katalon.ini</code> file.</span></li><li className="li substep"><span className="ph cmd">Input the <code className="ph codeph">tnsnames.ora</code> file and <code className="ph codeph">sqlnet.ora</code> file in  KS lib directory and point the TNS_ADMIN variable to this location. The TNS_ADMIN variable is set in the java options in <u className="ph u">substep (a)</u>.</span></li></ol></li><li className="li step stepexpand"><span className="ph cmd">In   <span className="ph uicontrol">Project Settings</span> &gt; <span className="ph uicontrol">Execution</span> &gt; <span className="ph uicontrol">Launch Arguments</span>, use the same <code className="ph codeph">-Doracle</code> arguments as in the <code className="ph codeph">katalon.ini</code> file. This is used during testing projects.</span><div className="itemgroup info"><img className="image" width={700} src={useBaseUrl("/cb254167-5216-48c0-a69e-8ede9a9ecadb/katalonini-file-example.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Restart Katalon Studio.</span></li><li className="li step stepexpand"><span className="ph cmd">Use the TNS Alias name for the database connection and test the connection.</span></li></ol>
