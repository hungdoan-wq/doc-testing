---
title: In-app Onboarding Tours
---

Katalon Studio provides interactive in-app tours to help beginners learn key testing workflows quickly. You can also access other help resources from [Katalon Help](/katalon-studio/get-started/workspace-settings/katalon-help).

To get started, open **Katalon Studio**, then go to **Help** > **Knowledge Hub**.

<img src="https://tw-cdn.katalon.com/katalon-studio/get-started/workspace-settings/ks_10.4.0_in_app_onboarding_tours/help-to-knowledge-hub.png" alt="Knowledge hub in KS" width="300" />

In the **Knowledge Hub**, select the in-app tour you want to explore. Follow the on-screen instructions to try out a sample test.

<img src="https://tw-cdn.katalon.com/katalon-studio/get-started/workspace-settings/ks_10.4.0_in_app_onboarding_tours/knowledge-hub-tab.png" alt="Knowledge hub in KS" width="700" />
