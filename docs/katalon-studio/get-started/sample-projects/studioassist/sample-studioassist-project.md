This sample project helps you get familiarized with StudioAssist's two features: Generate code and Explain code. These features aim to reduce your time and effort when developing and maintaining test scripts, as well as increase your productivity and improve your experience with Katalon Studio overall.

To learn more about StudioAssist, you can refer to [StudioAssist in Katalon Studio](https://docs.katalon.com/katalon-studio/create-test-cases/studioassist-in-katalon-studio).
:::info Requirements
- You have an active KSE license.
:::
## Open the StudioAssist sample project

To open the project, go to **File** > **New Sample Project** and select **Sample StudioAssist Tests Project**.

<img src="https://docs.katalon.com/5637a220-722f-11ee-9132-0242c7a41fd4/ks-studioassist-open-project.png"alt="The New Sample StudioAssist Test Project option."width="600" />

<br/>

Alternatively, you can download the StudioAssist sample project from our GitHub repository: [StudioAssist sample](https://github.com/katalon-studio-samples/studioassist-sample-usage).

### Trust dialog on first open

When you open a sample project for the first time, Katalon Studio will show a **"Trust and open this project"** dialog. This security prompt ensures you’re aware of the source before opening and potentially executing harmful scripts.

<img alt="Trust dialog studio assist"src="https://tw-cdn.katalon.com/katalon-studio/manage-projects/trust-dialog-pop-up/trust-dialog-studio-assist-test.png" width="500" />


In this dialog, you can:

- Review the project path.
- Decide whether to trust this project or all projects inside the parent folder.

:::note Notes 
- Trusting a parent folder also trusts all projects directly inside it, including the one you're opening.
- However, if this project contains subfolders with separate project files, those sub-projects won’t be trusted automatically. You'll still see the trust dialog when opening them.
:::
- Click **Trust Project** to continue, or **Don't Open** if you’re unsure.

Once opened, go to **Tests Explorer** panel > **Test Cases**. Here you will find the **Explain Code** and **Generate Code** folders, corresponding with the two features.

<img src="https://docs.katalon.com/563a8850-722f-11ee-9132-0242c7a41fd4/ks-studio-assist-test-case-folders.png" alt="Test case folders in the StudioAssist sample project" width="400" />

## Explain code

The **Explain Code** folder contains two test cases: **Explain Basic Script** and **Explain Regular Expression**. This section shows you how to use the code explaining feature with the **Explain Basic Script** test case.

1. Open the **Explain Basic Script** test case and switch to the **Script** view.
2. Select the script, then right-click > **StudioAssist (Beta)** > **Explain Code**.

## Generate call test case script

In Katalon Studio, you can call another test case as a test step in manual and script view. To learn more about this function, see
[Call test case in Katalon Studio](https://docs.katalon.com/katalon-studio/create-test-cases/call-test-case-in-katalon-studio).

This section demonstrates how to generate a call test case script with StudioAssist.

1. Open the **Generate Script Calling Other Test Case** in **Script** view.
2. Select the prompt, right-click > **StudioAssist (Beta)** > **Generate Code**. StudioAssist generates a test script with a Call test case step:

    <img src="https://docs.katalon.com/5633f8a0-722f-11ee-9132-0242c7a41fd4/ks-studio-assist-call-test-case.png" alt="The generated code with a Call test case step in Katalon Studio" width="600" />

    
3. Click **Run** from the main toolbar to execute the test script.

## Data-driven testing with StudioAssist

Data-driven testing (DDT) is a testing method that allows you to run a test script with various data sets. To learn more about DDT with Katalon Studio, see [Data-driven testing with Katalon Studio](https://docs.katalon.com/katalon-studio/data-driven-testing/data-driven-testing-with-katalon-studio).

You can use StudioAssist to generate test script that creates a CSV data file and data-driven script to perform data-driven testing. Do as follows:

**Generate CSV data file**

1. Open the **Generate Script Creating CSV data** test case in **Script** view.
2. Select the prompt, right-click > **StudioAssist (Beta)** > **Generate Code**. StudioAssist generates a test script that creates a CSV data file.

    <img src="https://docs.katalon.com/5617be10-722f-11ee-9132-0242c7a41fd4/ks-sample-studio-assist-run-CSV-script.png" alt="The test script that creates a CSV data file generated by StudioAssist" width="700" />

    
3. Run the generated test script.
    
    The CSV data file will be saved in the project folder on your machine.
    
4. In the **Tests Explorer** panel, right-click **Data Files** > **New** > **Test Data**.
    1. In the **New Test Data** dialog, enter a name and select **Data Type** as **CSV File**. Then click **OK**.
        
        <img src="https://docs.katalon.com/55ec4140-722f-11ee-9132-0242c7a41fd4/ks-sample-test-data-dialog.png" alt="The new test data dialog in Katalon Studio" width="400"/>
        
5. Click **Browse** and select the `test_data.csv` file to import to Katalon Studio.
    
   
    <img src="https://docs.katalon.com/562c3070-722f-11ee-9132-0242c7a41fd4/ks-sample-studio-assist-browse-data-file.png" alt="sa browse data file" width="700"/>
    

**Generate Data-Driven script**

1. Open the **Generate Data-Driven Script** in the **Script view**.
2. Generate code from the prompt to get the following result:
    
    <img src="https://docs.katalon.com/55fac030-722f-11ee-9132-0242c7a41fd4/ks-studio-assist-ddt-test-case.png" alt="Data-driven test script generated by StudioAssist" width="700"/>

    <br/>
    
    StudioAsisst fetches the predefined variables in the **Variables** tab of the test case.
    

**Perform data binding**

1. Switch to the **Data Binding** tab.
2. In the **Test Data** section, click **Add** and select the `CSV Test Data` file.
    
    <img src="https://docs.katalon.com/55cc0f10-722f-11ee-9132-0242c7a41fd4/ks-studio-assist-load-csv-file.png" alt="The Test Data Browser dialog." width="400"/>
    
    Then click **OK**.
    
1. Click **Map All** to quickly match the variables with the data file column headers that share the same name.
    
    <img src="https://docs.katalon.com/55d2c5d0-722f-11ee-9132-0242c7a41fd4/ks-studio-assist-map-all.png" alt="The Map All option in the Data Binding tab." width="600"/>
    
2. Click **Run** from the main toolbar to execute the test script.
