---
title: Migrate Katalon Studio from 8.x to 10.x
---

When upgrading Katalon Studio from 8.x to 10.x, you need to migrate step by step instead of skipping versions. Refer to the following guides to upgrade your project to the target version.

1. First, migrate from 8.x to 9.0.0 [Migrate Katalon Studio from 8.x → 9.0.0](https://docs.katalon.com/katalon-studio/get-started/workspace-settings/migrate-katalon-studio-from-8.x-to-9.0.0)
  
2. Then, migrate from 9.x to 10.x [Migrate Katalon Studio from 9.x → 10.x](https://docs.katalon.com/katalon-studio/get-started/workspace-settings/migrate-katalon-studio-from-9.x-to-10.x)
