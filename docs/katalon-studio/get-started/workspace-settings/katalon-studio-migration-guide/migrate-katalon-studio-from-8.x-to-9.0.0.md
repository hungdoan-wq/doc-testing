---
title: Migrate Katalon Studio from 8.x to 9.0.0
---
import useBaseUrl from '@docusaurus/useBaseUrl';



<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">In 9.0.0, <span className="ph">Katalon Studio</span> adopts Eclipse 2023-03 and Java 17. When upgrading from 8.x to 9.x, you might need to perform some additional steps for a smooth transition. This document provides guidance on whether you should upgrade from 8.x to 9.x.</p> 

## Upgrade with no action required

<div xmlns="http://www.w3.org/1999/xhtml" className="p">You can upgrade to <span className="ph">Katalon Studio</span> 9.x with no action required if:<ul className="ul"><li className="li">you are using Mac or Windows, not Linux</li><li className="li">your projects are not using customized default JRE with versions lower than 17</li><li className="li">you have not imported any external libraries to your projects</li><li className="li">you are not using any custom plugins (plugins that are not published by Katalon)</li><li className="li">you are not running BDD projects</li></ul></div>

## Upgrade with actions required

<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">For Linux users</strong><p className="p">If you are using Linux, you need to download and install OpenJDK 17. See <a className="xref" href="/katalon-studio/get-started/install-katalon-studio">Install Katalon Studio for Linux (GUI)</a>.</p></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">For projects with imported external libraries</strong><p className="p">You can extend the capabilities of <span className="ph">Katalon Studio</span> for specific uses by adding external Java <code className="ph codeph">.jar</code> libraries. However, there are a lot of libraries that have been deprecated from Java 8 to Java 17. For example, <code className="ph codeph">javax.xml.bind</code> should be replaced by <code className="ph codeph">jakarta.xml.bind</code>; or <code className="ph codeph">sun.misc.BASE64Decoder</code> should be replaced by <code className="ph codeph">java.util.Base64</code>. </p><p className="p">If your projects are not working normally in <span className="ph">Katalon Studio</span> 9.x, you might need to check and update your imported external libraries. See <a className="xref" href="/katalon-studio/manage-projects/project-settings/library-management-in-katalon-studio#add-external-libraries-to-a--project">Add external libraries to a  project</a>.</p><p className="p"><strong className="ph b">For projects with installed custom plugins</strong></p><p className="p">You can use plugins published by Katalon without any additional changes. However, if you use plugins published by the community or you build your own plugins to use, and the plugin is not working properly in <span className="ph">Katalon Studio</span> 9.x, you might need to upgrade plugins with libraries that are compatible with Java 17.</p><div className="p">You can refer to the following sources for deprecated libraries:<ul className="ul"><li className="li"><a className="xref j-external-link" href="https://docs.oracle.com/en/java/javase/11/docs/api/deprecated-list.html" target="_blank">Oracle JDK deprecated API list</a></li><li className="li"><a className="xref j-external-link" href="https://docs.oracle.com/en/java/javase/20/migrate/removed-apis.html#GUID-9EF06707-9441-433E-BA50-9DD99F1C07F4" target="_blank">Oracle JDK Migration guide</a></li></ul></div></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">For projects with custom keyword plugins</strong><p className="p">You might not be able to use custom keywords plugin in Katalon Studio 9.x. This is because Katalon Gradle Plugin does not support compiling Groovy 3.0, which is bundled with Katalon Studio 9.x. To use the plugins, first re-build your custom keyword plugins in Katalon Studio 9.x, then put the plugins in the <span className="ph uicontrol">Plugins</span> folder of your project.</p></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">For users with BDD projects</strong><div className="p">You need to add a <code className="ph codeph">@BeforeTestCase</code> listener to your project. To learn more about test listeners, see <a className="xref" href="/katalon-studio/create-test-cases/test-fixtures-and-test-listeners-test-hooks-in-katalon-studio#test-listeners-test-hooks">Test Listeners (Test Hooks)</a>.<div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li">You don't need to modify every script in your project, you just need to add this test listener <strong className="ph b">ONCE</strong>.</li></ul></div></div><div className="p">In the <span className="ph uicontrol">Tests Explorer</span> panel, right click <span className="ph uicontrol">Test Listeners</span> and create a new test listener. Then, copy and paste the following code to the listener script:<pre className="pre codeblock"><code>import com.kms.katalon.core.cucumber.keyword.internal.CucumberGlueGenerator{"\n"}{"\n"}@BeforeTestCase{"\n"}def beforeTestCase(TestCaseContext context) {"{"}{"\n"}{"  "}CucumberGlueGenerator.addDefaultPackages();{"\n"}{"}"}</code></pre>Your test listener should look like this:<img className="image" width={650} src={useBaseUrl("/ee5595d0-569b-11ee-bc71-0242c7a41fd4/ks-900-before-test-case.png")} /></div><p className="p">Save the test listener and you can execute your BDD projects in 9.x as normal.</p><p className="p">To learn more about working with BDD feature files, see <a className="xref" href="/katalon-studio/bdd-testing/work-with-bdd-feature-files-in-katalon-studio">Work with BDD feature files in Katalon Studio</a>.</p></div>

## Should not upgrade

<p xmlns="http://www.w3.org/1999/xhtml" className="p">With <span className="ph">Katalon Studio</span> 8.x, you can set your desired JRE package from v8 to v14 as the default one to compile and run test projects. To learn more about setting desired JRE package, see <a className="xref" href="/katalon-studio/get-started/workspace-settings/katalon-studio-preferences/set-a-new-default-jre-for-test-projects-in-katalon-studio">Set a new default JRE for test projects in <span className="ph">Katalon Studio</span></a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">In version 9.0.0, we upgraded the Eclipse framework to version 2023-03, which requires at least Java 17. Therefore, you should not upgrade to 9.0.0 and later until your projects can run with JRE 17.</p>
