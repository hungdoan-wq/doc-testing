<p xmlns="http://www.w3.org/1999/xhtml" className="p">The Katalon Studio for Bamboo plugin enables you to automatically download, deploy, and execute Katalon Studio tests on a Bamboo server.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">On this page, you'll learn how to install the plugin, configure test execution, and manage test artifacts.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">You can try it for free on the <a className="xref j-external-link" href="https://marketplace.atlassian.com/apps/1220235/katalon-devops-for-bamboo" target="_blank">Atlassian Marketplace</a>.<div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p"> Katalon TestOps CI is an easier way to execute or schedule Katalon Studio tests remotely. See <a className="xref" href="#">Schedule test runs in TestOps</a>. </p></li></ul></div></div>

## <a id="task-1226" class="anchor_top_offset"/>Install the Bamboo add-on

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li">An active Katalon Runtime Engine license.</li><li className="li">Bamboo administrative permissions to configure the integration.</li></ul></div>
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To install the add-on, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Sign in to your Bamboo instance as an admin.</span></li><li className="li step"><span className="ph cmd">Click <span className="ph uicontrol">Administration</span> and select <span className="ph uicontrol">MANAGE APPS</span>.</span></li><li className="li step"><span className="ph cmd">Click <span className="ph uicontrol">Find new apps</span> from the left-hand side of the page. <svg xmlns="http://www.w3.org/2000/svg" height={458} viewBox="0 0 478 458" width={478} x={0} y={0}><image height={458} width={478} actuate="onLoad" href="https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/bamboo-integration/find-apps.png" show="embed" type="simple" /></svg></span></li><li className="li step"><span className="ph cmd">Locate <span className="ph uicontrol">Katalon for Bamboo</span> via search.</span></li><li className="li step"><span className="ph cmd">Click <span className="ph uicontrol">Try it free</span> to start your trial or  <span className="ph uicontrol">Buy now</span> to purchase a license for executing Katalon Tests.</span></li><li className="li step"><span className="ph cmd">Enter your information and click <span className="ph uicontrol">Generate license</span> when redirected to MyAtlassian.</span></li><li className="li step"><span className="ph cmd">Click <span className="ph uicontrol">Apply license</span>.</span></li></ol> 

## <a id="task-9271" class="anchor_top_offset"/>Configure the integration

<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">Once you have installed the plugin, you  need to configure the <strong className="ph b">Execute Katalon Studio Tests</strong> task to complete the     integration:</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Create and configure a new plan in Bamboo. See <a className="xref j-external-link" href="https://confluence.atlassian.com/bamboo/creating-a-plan-289276868.html" target="_blank">Creating a plan (external link).</a></span></li><li className="li step stepexpand"><span className="ph cmd">Add <strong className="ph b">Execute Katalon Studio Tests</strong> to your tasks of the newly created plan.</span><ol type="a" className="ol substeps"><li className="li substep"><span className="ph cmd">In <span className="ph uicontrol">Tasks</span>, click <span className="ph uicontrol">Add task</span>.</span></li><li className="li substep"><span className="ph cmd">In the <span className="ph uicontrol">Task types</span> window, locate <strong className="ph b">Execute Katalon Studio Tests</strong> via search or find it under the Tests category.</span></li><li className="li substep"><span className="ph cmd">Add <strong className="ph b">Execute Katalon Studio Tests</strong> to your task list.</span></li></ol><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/bamboo-integration/bamboo-tasktypes.png")} /><br /><br /></div></li><li className="li step stepexpand"><span className="ph cmd">Configure the <strong className="ph b">Execute Katalon Studio Tests</strong> task and click <span className="ph uicontrol">Save</span> to create it.</span><div className="itemgroup info">Configuration instructions:</div><div className="itemgroup info"><ul className="ul"><li className="li"><p className="p"><span className="ph uicontrol">Download Katalon Version</span>: Specify the Katalon Studio (prior to 7.0) or Katalon Runtime Engine (7.0+) that is downloaded automatically to execute the tests. Or,</p></li><li className="li"><p className="p"><span className="ph uicontrol">Use pre-installed Katalon Studio</span>: Provide a link to Katalon Studio (prior to 7.0) or Katalon Runtime Engine (7.0+) app that has been already installed.</p></li><li className="li"><p className="p"><span className="ph uicontrol">Command arguments</span>: You can enter the arguments directly in the text area or copy and paste the generated command from Katalon Studio.</p></li></ul><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">Remove any irrelevant argument such as ​<code className="ph codeph">-runmode</code>​. See ​<a className="xref" href="#">Command-line syntax in Katalon Runtime Engine</a>​ for more details.</p></li></ul></div></div><div className="itemgroup info"><p className="p"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/bamboo-integration/command.png")} /><br /><br /></p><ul className="ul"><li className="li"><p className="p"><span className="ph uicontrol">Xvfb-run configuration</span>: For more details, see <a className="xref j-external-link" href="https://manpages.ubuntu.com/manpages/xenial/man1/xvfb-run.1.html" target="_blank">xvfb-run</a>. If unsure, adjust only the resolution to 1024x768x24 and leave other options unchanged.</p></li></ul></div></li></ol>
