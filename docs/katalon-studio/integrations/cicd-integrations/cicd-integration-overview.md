## <a id="concept-4352" class="anchor_top_offset"/>Use TestCloud in CI/CD pipelines

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">To execute tests in <span className="ph">TestCloud</span> environments with <span className="ph">Katalon Runtime Engine</span>, you only need a <span className="ph">TestCloud</span> subscription or trial; <span className="ph">Katalon Runtime Engine</span> license is not required. This also enables you to use <span className="ph">TestCloud</span> in any CI/CD pipelines configured with <span className="ph">KRE</span>.</p>
