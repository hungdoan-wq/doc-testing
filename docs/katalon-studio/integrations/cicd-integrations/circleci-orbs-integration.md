<p xmlns="http://www.w3.org/1999/xhtml" className="p">Orbs are shareable packages of configuration elements such as jobs, commands, and executors. They facilitate streamlined integration across various projects. For further details on orbs, refer to the <a className="xref j-external-link" href="https://circleci.com/docs/2.0/orb-intro/" target="_blank">Orbs overview in the CircleCI documentation</a>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">This guide demonstrates how to use the Katalon orb for executing Katalon tests within your CircleCI CI/CD pipeline. For optimal functionality and access to new features, download the latest Katalon orb on CircleCI: <a className="xref j-external-link" href="https://circleci.com/developer/orbs/orb/katalon/katalon-studio" target="_blank">katalon/katalon-studio</a>.<div className="note note note_note"><span className="note__title">Note:</span> <div className="p"><ul className="ul"><li className="li"><p className="p">Katalon TestOps CI is an easier way to execute or schedule Katalon Studio tests remotely. See <a className="xref" href="/katalon-platform/execute/test-execution-with-testops/schedule-test-runs-in-testops">Schedule test runs in TestOps</a>.</p></li></ul></div></div></div>

## <a id="task-7531" class="anchor_top_offset"/>Setup and configuration

<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li">An active Katalon Runtime Engine license. ## <a id="task-8604" class="anchor_top_offset"/>Execute tests with Katalon orb

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Katalon orb automatically executes Katalon tests after each commit to the configured GitHub repository.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To execute tests with Katalon orb and download test execution reports, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to CircleCI,  navigate to <span className="ph uicontrol">Project</span> &gt; <span className="ph uicontrol">Branch</span>, and select <span className="ph uicontrol">Run Pipeline</span>.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/circleci/run%20pipeline.png")} alt="run pipeline" /><br /><br /></div></li><li className="li step stepexpand"><span className="ph cmd">After running Katalon tests in CircleCI, you can download test execution reports in the <span className="ph uicontrol">ARTIFACTS</span> tab.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/integration-circleci/circleci5.png")} /><br /><br /></div></li></ol>
