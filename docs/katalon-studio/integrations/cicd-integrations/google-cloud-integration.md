<p xmlns="http://www.w3.org/1999/xhtml" className="p">Cloud Build is a service on the Google Cloud Platform (GCP) that automates the build, test, and deployment processes for projects. For more details, refer to the <a className="xref j-external-link" href="https://cloud.google.com/build/docs" target="_blank">Cloud Build documentation</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Integrating Katalon with Cloud Build helps streamline your CI/CD pipeline and ensures automatic execution of Katalon test scripts whenever changes occur in the source code. </p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">This tutorial shows you how to configure the <code className="ph codeph">cloudbuild.yml</code> file, create a Google Cloud secret, and set up a Cloud Build trigger.<div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">Find the sample project in our GitHub repository: <a className="xref j-external-link" href="https://github.com/katalon-studio-samples/ci-samples" target="_blank">katalon-studio-samples/ci-samples</a>.</p></li></ul></div><div className="note important note_important"><span className="note__title">Important:</span> <ul className="ul"><li className="li">A valid Katalon API key. See <a className="xref" href="#">Generate a Katalon API Key</a>.</li><li className="li">A GCP project. See Google Workspace documentation: <a className="xref j-external-link" href="https://developers.google.com/workspace/guides/create-project" target="_blank">Create a Google Cloud project</a>.</li><li className="li">Google Cloud Build API enabled for your Google Cloud project. See Google Cloud documentation: <a className="xref j-external-link" href="https://cloud.google.com/endpoints/docs/openapi/enable-api" target="_blank">Enabling an API in your Google Cloud project</a>.</li><li className="li">Secret Manager API enabled for your GCP project. See Google Cloud documentation: <a className="xref j-external-link" href="https://cloud.google.com/build/docs/securing-builds/use-secrets" target="_blank">Use secrets from Secret Manager</a>.</li></ul></div>After setting up the GCP project, you need to configure the following components:<ul className="ul"><li className="li">A <code className="ph codeph">cloudbuild.yml</code> file at the root directory of your repository that contains the build configuration for Cloud Build.</li><li className="li">A Google Cloud secret to store your Katalon API key.</li></ul></div>

## <a id="task-4911" class="anchor_top_offset"/>Configure the <code xmlns="http://www.w3.org/1999/xhtml" className="ph codeph">cloudbuild.yml</code>  file

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">The  <code className="ph codeph">cloudbuild.yml</code> file  specifies the instructions for Cloud Build to automate the building, testing, and deploying of your Katalon project.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">Here in the sample GitHub repository, we have the following  <code className="ph codeph">cloudbuild.yml</code> file:</p><pre className="pre codeblock"><code>steps:{"\n"}- name: 'docker'{"\n"}{"  "}args: ['pull', 'katalonstudio/katalon']{"\n"}- name: 'docker'{"\n"}{"  "}entrypoint: 'sh'{"\n"}{"  "}args: ['-c', 'docker run -t --rm -v /workspace:/tmp/project katalonstudio/katalon katalonc.sh -projectPath=/tmp/project -browserType="Chrome" -retry=0 -retryStrategy=immediately -testSuiteCollectionPath="Test Suites/Simple Test Suite Collection" --config -webui.autoUpdateDrivers=true -apiKey=$$KATALON_API_KEY']{"\n"}{"  "}secretEnv: ['KATALON_API_KEY']{"\n"}availableSecrets:{"\n"}{"  "}secretManager:{"\n"}{"  "}- versionName: projects/$PROJECT_ID/secrets/KATALON_API_KEY/versions/1{"\n"}{"    "}env: 'KATALON_API_KEY'{"\n"}</code></pre><p className="p">In the build configuration file, there are two build steps:</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Use a <code className="ph codeph">docker</code> cloud builder to pull the       <code className="ph codeph">katalonstudio/katalon</code> Docker image from Docker       Hub.</span><div className="itemgroup info"><ul className="ul"><li className="li">In the <strong className="ph b">args</strong> field, specify an image version using the syntax           <code className="ph codeph">katalonstudio/katalon:&lt;version_tag&gt;</code>. For example,           <code className="ph codeph">katalonstudio/katalon:8.1.2</code>.</li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Use a <code className="ph codeph">docker</code> cloud builder to run the       <code className="ph codeph">katalonstudio/katalon</code> image as a container and execute       the tests stored in your GitHub repository.</span><ol type="a" className="ol substeps"><li className="li substep"><span className="ph cmd">In the <strong className="ph b">args</strong> field, set your <code className="ph codeph">katalonc</code> commands.  For a  list of <code className="ph codeph">katalonc</code>           supported arguments, refer to <a className="xref" href="#">Command             syntax</a>.</span></li><li className="li substep"><span className="ph cmd"> In the <strong className="ph b">secretEnv</strong> field, input the           environment variables, such as <code className="ph codeph">KATALON_API_KEY</code>, to  use the           secret named <code className="ph codeph">KATALON_API_KEY</code>.</span></li></ol></li></ol> 

## <a id="id_3-k4pup1gm" class="anchor_top_offset"/>Create a Google Cloud secret for Katalon API key

<p xmlns="http://www.w3.org/1999/xhtml" className="p">As specified in the build configuration file, the <code className="ph codeph">KATALON_API_KEY</code> secret represents your Katalon API key. You need to define the secret for your project.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">For detailed instructions on creating a Google Cloud secret, refer to this Google Cloud guide: <a className="xref j-external-link" href="https://cloud.google.com/secret-manager/docs/creating-and-accessing-secrets" target="_blank">Create a secret</a>.</p>

## <a id="id_4-1od4rl36" class="anchor_top_offset"/>Create and test your build trigger

<p xmlns="http://www.w3.org/1999/xhtml" className="p">A Cloud Build trigger automatically starts a build whenever you   make changes to your source code. You need to connect Cloud Build   to the sample GitHub repository and then create a trigger that   automatically monitors changes and builds code.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">For detailed instructions on connecting to repositories and   building triggers, see <a className="xref j-external-link" href="https://cloud.google.com/build/docs/automating-builds/create-manage-triggers" target="_blank">Create     and manage build triggers</a>.</p> 

### <a id="id_5-hbqwisp8" class="anchor_top_offset"/>Create a trigger

<p xmlns="http://www.w3.org/1999/xhtml" className="p">In our example, a trigger is created to build the code automatically whenever a <span className="ph uicontrol">Push to branch</span> event occurs.</p>
