<p xmlns="http://www.w3.org/1999/xhtml" className="p">Docker is a platform for running applications in an isolated   environment called a Docker container. Applications like Jenkins   can be downloaded as read-only images, each of which is run in   Docker as a container.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">However, when your Jenkins is installed on a dynamic Docker   hosted in Ubuntu without GUI, you might not be able to configure   build and integration with Katalon Studio from the user interface   normally.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This tutorial will guide you through configuring and building   your Katalon Project with Jenkins on Docker hosted in Ubuntu. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Your Katalon project will run with the Katalon Studio Docker image. Katalon Studio and Katalon Runtime Engine do not need to be installed on your local machine. </p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p">You can find the Katalon Studio Docker Image on Docker Hub here: <a className="xref j-external-link" href="https://hub.docker.com/r/katalonstudio/katalon" target="_blank">Docker Hub</a>.<div className="note important note_important"><span className="note__title">Important:</span> <ul className="ul"><li className="li">An active floating <a className="xref" href="/katalon-studio/katalon-studio-enterprise-and-katalon-runtime-engine-license/katalon-runtime-engine-floating-license">Katalon Runtime Engine license</a>.</li><li className="li">Docker and Jenkins already installed and configured. For installation instructions, see this Jenkins guide: <a className="xref j-external-link" href="https://www.jenkins.io/doc/book/installing/docker/" target="_blank">Installing Docker</a>.</li></ul></div></div>

## <a id="task-9127" class="anchor_top_offset"/>Integrate Jenkins with Docker

<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><p className="p">To integrate with Docker on Jenkins, you need to install the <strong className="ph b">Docker plugin</strong> and <strong className="ph b">Docker Pipeline</strong>, then set an environment path to Jenkins. Do as follows:</p></section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Install plugins.</span><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">Open Jenkins, then go to <span className="ph uicontrol">Dashboard</span><strong className="ph b"> &gt; </strong><span className="ph uicontrol">Manage Jenkins</span><strong className="ph b"> &gt; </strong><span className="ph uicontrol">Manage Plugins</span>.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-docker/new-plugin.png")} width={500} alt="manage plugins" /><br /><br /></div></li><li className="li substep substepexpand"><span className="ph cmd">The Plugin Manager page appears. In the <span className="ph uicontrol">Available</span> tab, search for <strong className="ph b">Docker plugin</strong> and <strong className="ph b">Docker Pipeline</strong>, then select them.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-docker/plugins.png")} alt="plugins" /><br /><br /></div></li><li className="li substep substepexpand"><span className="ph cmd">Click <strong className="ph b">Install without restart</strong>.</span></li></ol></li><li className="li step stepexpand"><span className="ph cmd">Add an environment path.</span><div className="itemgroup info"><p className="p">To run Docker commands from Jenkins, you need to add an environment path to Jenkins. The <code className="ph codeph">PATH</code> specifies where to find the folder containing Docker commands.</p><p className="p">Go to <span className="ph uicontrol">Dashboard</span><strong className="ph b"> &gt; </strong><span className="ph uicontrol">Manage Jenkins</span><strong className="ph b"> &gt; </strong><span className="ph uicontrol">Configure System</span><strong className="ph b"> &gt; </strong><span className="ph uicontrol">Global properties</span>. Select the <span className="ph uicontrol">Environment variables</span> to add a global variable named <code className="ph codeph">PATH+EXTRA</code> with this value: <code className="ph codeph">usr/local/bin</code>.</p><div className="p"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-docker/Global-properties.png")} alt="global properties" /><br /><br /><div className="note note note_note"><span className="note__title">Note:</span> To find the correct Docker installation path, open <strong className="ph b">Terminal</strong>, copy and paste the following command line: <code className="ph codeph">which docker</code>. The result will tell you where the Docker is.</div></div></div></li></ol> 

## <a id="id_4-xlba1gl8" class="anchor_top_offset"/>Upload your Katalon project on Jenkins

:::info notes
- Ensure Docker is running and that both the **Docker plugin** and **Docker Pipeline** are active on Jenkins.
- Clone or download our sample CI/CD project at our [GitHub repository](https://github.com/katalon-studio-samples/ci-samples).
:::
<p xmlns="http://www.w3.org/1999/xhtml" className="p">You have two options for uploading your Katalon project to Jenkins:</p> 
<ul xmlns="http://www.w3.org/1999/xhtml" className="ul"><li className="li"><p className="p">From a Git repository.</p></li><li className="li"><p className="p">From your local workspace.</p></li></ul> 

### <a id="task-2848" class="anchor_top_offset"/>Upload a Git repository

<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To upload your Katalon project as a Git repository to Jenkins, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Prepare your Katalon project repository on GitHub.</span></li><li className="li step stepexpand"><span className="ph cmd">In the Jenkins Dashboard, go to <span className="ph uicontrol">New Item</span> and create a <span className="ph uicontrol">Freestyle project</span>.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-docker/new-item.png")} alt="new item" /><br /><br /></div></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">Source Code Management</span> section, choose <span className="ph uicontrol">Git</span>.</span></li><li className="li step stepexpand"><span className="ph cmd">Enter your repository URL, select branches to build, repository browser, and additional behaviors, if any.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-docker/git.png")} alt="add git repository" /><br /><br /></div></li></ol> 

### <a id="task-5194" class="anchor_top_offset"/>Upload in the local workspace

<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To upload your Katalon project from a local workspace to Jenkins, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step"><span className="ph cmd">Put your CI/CD project folder in this directory:       <code className="ph codeph">Users/Your_user_name/.jenkins/workspace</code>. Copy your       project folder name.</span></li><li className="li step"><span className="ph cmd">In the Jenkins Dashboard, go to <span className="ph uicontrol">New Item</span> and       create a <span className="ph uicontrol">Freestyle project</span>. Name your project the       same name as your project folder in your local Jenkins       workspace.</span></li></ol>
