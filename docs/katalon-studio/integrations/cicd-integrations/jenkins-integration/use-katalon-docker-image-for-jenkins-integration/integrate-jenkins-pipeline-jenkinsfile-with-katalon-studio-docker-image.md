This tutorial explains how to integrate a Jenkins Pipeline (Jenkinsfile) with the Katalon Studio Docker Image. This image contains up-to-date browsers, including Google Chrome, Mozilla Firefox, and Katalon Studio.

Using the Katalon Studio Docker Image, you don't need to install Katalon Studio and Katalon Runtime Engine on your local machine.

Find Katalon Studio Docker Image at [Docker Hub](https://hub.docker.com/r/katalonstudio/katalon/).

:::tip requirements
- Jenkins installed. Follow the instructions in this Jenkins document for installation: [Installing Jenkins](https://www.jenkins.io/doc/book/installing/).
- Docker installed. For installation details, see [Get Docker](https://docs.docker.com/get-docker/).
- An active Katalon Runtime Engine floating license. To learn more about types of licenses, refer to this document: [KRE floating license](/katalon-studio/katalon-studio-enterprise-and-katalon-runtime-engine-license/katalon-runtime-engine-floating-license).
:::

## <a id="task-1009" class="anchor_top_offset"/>Upload your Pipeline script

<section xmlns="http://www.w3.org/1999/xhtml" className="section context"><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">Make sure you have Docker open, with <strong className="ph b">Docker plugin</strong> and <strong className="ph b">Docker Pipeline</strong> activated on Jenkins.</p></div>To upload your pipeline script to Jenkins, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">In the Jenkins Dashboard, go to <span className="ph uicontrol">New Item </span> and create a <span className="ph uicontrol">Pipeline</span> project.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-plugin-windows/create-pipeline.png")} /><br /><br /></div></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">Definition</span> dropdown list,  choose between <span className="ph uicontrol">Pipeline script</span> or <span className="ph uicontrol">Pipeline script from SCM</span>, depending on where you store your Jenkinsfile.</span><div className="itemgroup info">The <span className="ph uicontrol">Pipeline script from SCM</span> instructs Jenkins to obtain your Pipeline from Source Control Management (SCM), which will be your locally cloned Git repository. <span className="ph uicontrol">Copy path</span> to get the script path.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-plugin-windows/KS-JENKINS-Quickly-go-to-Jenkins-file-in-Git.png")} alt="Quickly get Jenkinsfile path in Git project" /><br /><br /></div></li><li className="li step stepexpand"><span className="ph cmd">Specify the Jenkinsfile path from your Git project in the <span className="ph uicontrol">Script Path</span> box.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/jenkins-plugin-windows/KS-JENKINS-Add-Jenkinspath-2.png")} alt="Jenkinsfile path" /><br /><br /><p className="p">You can see our <a className="xref j-external-link" href="https://github.com/katalon-studio-samples/ci-samples/blob/master/Jenkinsfile" target="_blank">sample Jenkinsfile</a> for MacOS/Linux. In case you are using Windows, replace the <code className="ph codeph">sh</code> command in this sample Jenkinsfile with the <code className="ph codeph">bat</code> command:</p><div className="p"><pre className="pre codeblock"><code>steps {"{"}{"\n"}bat ''{"\n"}{"}"}</code></pre>For example, we want to run the <strong className="ph b">TS_RegressionTest</strong> test suite from the <strong className="ph b">CI samples</strong> project with the Chrome browser in Windows. We adjust the sample Jenkinsfile as follows:</div><div className="p"><pre className="pre codeblock"><code>pipeline {"{"}{"\n"}{"    "}agent any{"\n"}{"    "}stages {"{"}{"\n"}{"        "}stage('Test') {"{"}{"\n"}{"            "}steps {"{"}{"\n"}{"                "}dir('/Users/&lt;user_name&gt;/Downloads/ci-samples-master'){"{"}{"\n"}{"                    "}bat 'docker run -t --rm -v "$(pwd)":/tmp/project katalonstudio/katalon katalonc.sh -projectPath=/tmp/project -browserType="Chrome" -retry=0 -statusDelay=15 -testSuitePath="Test Suites/TS_RegressionTest" -apiKey=&lt;your-api-key&gt;'{"\n"}{"                "}{"}"}{"\n"}{"            "}{"}"}{"\n"}{"        "}{"}"}{"\n"}{"    "}{"}"}</code></pre></div><div className="p"><div className="note note note_note"><span className="note__title">Note:</span> <p className="p">After cloning our sample Jenkinsfile to your repository, customize the below command lines for your purposes:</p>           <ul className="ul"><li className="li"><code className="ph codeph">&lt;your-project-folder&gt;</code>: the direct path to your project folder in the local machine.</li><li className="li"><code className="ph codeph">&lt;your_API_Key&gt;</code>: the API key verifies your credentials. The command-line options of API Key, including <code className="ph codeph">-apiKey=&lt;Your_API_Key&gt;</code> and <code className="ph codeph">-apikey=&lt;Your_API_Key&gt;</code> are both accepted.
