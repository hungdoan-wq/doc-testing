<p xmlns="http://www.w3.org/1999/xhtml" className="p">App Center Test supports only tests using frameworks such as Appium written in Java with JUnit. Therefore, Katalon users cannot directly execute their tests on App Center Test.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">However, you can execute your Katalon test scripts with devices provided on App Center Test by using <span className="ph uicontrol">sideload</span> to package Katalon projects in JUnit format. For more information, see Visual Studio App Center documentation: <a className="xref j-external-link" href="https://learn.microsoft.com/en-us/appcenter/test-cloud/" target="_blank">App Center Test</a> and <a className="xref j-external-link" href="https://learn.microsoft.com/en-gb/appcenter/test-cloud/frameworks/appium/" target="_blank">Preparing Appium Tests for Upload</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This tutorial shows you how to integrate with App Center Test using <span className="ph uicontrol">sideload</span>. We also provide the <span className="ph uicontrol">KatalonDemoProject</span> as a usage example.</p>

## <a id="task-6391" class="anchor_top_offset"/>Upload  KatalonDemoProject

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">This section provides a usage example on how to package a project, upload   sideload to App Center   Test, and start a test run in App Center   Test.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To upload the KatalonDemoProject to App Center Test using sideload, follow these steps:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Clone or download sideload from our       repository at <a className="xref j-external-link" href="https://github.com/katalon-studio/sideload" target="_blank">Katalon Studio sideload</a>.</span></li><li className="li step stepexpand"><span className="ph cmd">Open the workspace of the usage example project by following the       path: <code className="ph codeph">src/test/resources/KatalonDemoProject.zip</code>.</span><div className="itemgroup info"><p className="p">On App Center Test, create and start a new test run. See <a className="xref j-external-link" href="https://docs.microsoft.com/en-us/appcenter/test-cloud/starting-a-test-run#new-test-run" target="_blank">Starting           a test run</a>.</p></div><div className="itemgroup info"><ul className="ul"><li className="li"><p className="p">Device: Android 7.1.1 or prior. Ex: Motorola Nexus 6</p></li><li className="li"><p className="p">Test framework: Appium</p></li></ul></div></li><li className="li step stepexpand"><span className="ph cmd">Execute the file       <code className="ph codeph">package.bat</code>/<code className="ph codeph">package.sh</code> to pack your sideload project.</span></li><li className="li step stepexpand"><span className="ph cmd">Configure in the file <code className="ph codeph">upload.sh</code>/<code className="ph codeph">upload.bat</code>.</span></li><li className="li step stepexpand"><span className="ph cmd">Execute the file <code className="ph codeph">upload.sh</code>/<code className="ph codeph">upload.bat</code> to upload and run your sideload project in App Center       Test.</span></li><li className="li step stepexpand"><span className="ph cmd">View test reports on App Center Test. See Microsoft documentation: <a className="xref j-external-link" href="https://learn.microsoft.com/en-us/appcenter/test-cloud/test-reports" target="_blank">Test reports</a>.</span></li></ol> 

## <a id="troubleshooting-xvm075in" class="anchor_top_offset"/>Troubleshooting: <code xmlns="http://www.w3.org/1999/xhtml" className="ph codeph">Object is null</code>  error

<section xmlns="http://www.w3.org/1999/xhtml" className="section condition"><p className="p">When handling relative object paths in the App Center test script, you might encounter <code className="ph codeph">Object is null</code> error message.</p></section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p"><span className="ph">Katalon Studio</span> version earlier than 7.9.1 cannot handle relative object path, you must  direct App Center to use <span className="ph">Katalon Studio</span> version 8.0.0 onwards. </p></section><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd"> From the <code className="ph codeph">SideloadTest.java</code> file in the java folder <code className="ph codeph">src/test/java/com.katalon.sideload/SideloadTest.java</code>, indicate version 8.0.0 by assigning the variable <code className="ph codeph">String katalonVersion</code>.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("/8304a440-8e88-11ee-ab4f-0242c7a41fd4/KS_-_App_Center_sideload_-_SideloadTest.jpeg")} alt="katalonVersion in SideloadTest.java" /></div></li><li className="li step stepexpand"><span className="ph cmd"> From the <code className="ph codeph">KatalonDownloadUtils.java</code> file, use <code className="ph codeph">KatalonVersion version = katalonVersion</code>.</span><div className="itemgroup info"><img className="image" src={useBaseUrl("/83531260-8e88-11ee-ab4f-0242c7a41fd4/KS_-_App_Center_sideload_-_KatalonDownloadUtils.png")} alt="katalonVersion in KatalonDownloadUtils.java" /></div></li></ol></section></div>
