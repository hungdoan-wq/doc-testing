## Requirements

<ul xmlns="http://www.w3.org/1999/xhtml" className="ul"><li className="li"><p className="p">A GitHub repository containing your Katalon Studio project.</p></li><li className="li"><p className="p">OpenShift environment set up with CodeReady Containers (CRC). See <a className="xref j-external-link" href="https://crc.dev/crc/getting_started/getting_started/installing/" target="_blank">Installing CRC</a>.</p></li><li className="li"><p className="p">OpenShift CLI, the <code className="ph codeph">oc</code> command, installed and configured. See <a className="xref j-external-link" href="https://docs.openshift.com/container-platform/4.8/cli_reference/openshift_cli/getting-started-cli.html" target="_blank">Getting started with the OpenShift CLI</a>.</p></li><li className="li"><p className="p">Docker installed. See <a className="xref j-external-link" href="https://docs.docker.com/get-docker/" target="_blank">Get Docker</a>.</p></li><li className="li"><p className="p">Visual Studio Code or a similar editor to create a YAML file. See <a className="xref j-external-link" href="https://code.visualstudio.com/Docs/setup/setup-overview" target="_blank">Setting up Visual Studio Code</a>.</p></li></ul> 

## <a id="task-3058" class="anchor_top_offset"/>Run Katalon tests in OpenShift

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">Below is the process for running Katalon tests in an OpenShift cluster. This includes gaining access to OpenShift, creating a custom Docker image for Katalon, and deploying the job using the CLI. Follow these steps to set up your environment and run your tests efficiently.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Log in to OpenShift</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Open a terminal and input <code className="ph codeph">crc start</code>.</span><div className="itemgroup info">The output will provide login information for the OpenShift and the <code className="ph codeph">oc</code> command line interface.</div></li><li className="li step stepexpand"><span className="ph cmd">Log in to your OpenShift cluster.</span><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">Configure the <code className="ph codeph">oc</code> command line interface by running this command:</span><div className="itemgroup info"><pre className="pre codeblock"><code>eval $(crc oc-env)</code></pre></div></li><li className="li substep substepexpand"><span className="ph cmd">Log in to OpenShift as an administrator using the provided credentials.</span><div className="itemgroup info"><pre className="pre codeblock"><code>oc login -u kubeadmin -p &lt;admin-password&gt; https://api.crc.testing:6443</code></pre></div></li></ol></li></ol> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Create a custom Docker Image for Katalon</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps" start={3}><li className="li step stepexpand"><span className="ph cmd">Create a directory for your custom image by running these commands:</span><div className="itemgroup info"><pre className="pre codeblock"><code>mkdir ~/katalon-custom-image{"\n"}cd ~/katalon-custom-image</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">Create a file named <code className="ph codeph">Dockerfile</code> in the terminal.</span><div className="itemgroup info"><pre className="pre codeblock"><code>nano Dockerfile</code></pre><div className="p">Then, add the following content:<pre className="pre codeblock"><code>FROM katalonstudio/katalon{"\n"}USER root{"\n"}RUN apt-get update &amp;&amp; \{"\n"}{"    "}apt-get install -y libxi6 libgconf-2-4 libstdc++6 xvfb &amp;&amp; \{"\n"}{"    "}rm -rf /var/lib/apt/lists/*{"\n"}USER katalon</code></pre>Save the file and exit the text editor (press Ctrl+X, then Y, and then Enter).</div></div></li><li className="li step stepexpand"><span className="ph cmd">Build the Docker Image.</span><div className="itemgroup info"><pre className="pre codeblock"><code>docker build -t katalon-custom .</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">Tag and push the Docker Image.</span><div className="itemgroup info"><pre className="pre codeblock"><code>docker tag katalon-custom &lt;dockerhub-username&gt;/katalon-custom:latest{"\n"}docker push &lt;dockerhub-username&gt;/katalon-custom:latest</code></pre></div></li></ol> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Deploy and run your Katalon tests in the OpenShift cluster</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps" start={7}><li className="li step stepexpand"><span className="ph cmd">Open Visual Studio Code and create a YAML file for the Katalon job.</span><div className="itemgroup info">For example, a file named <code className="ph codeph">katalon-job.yaml</code> with the following content:<div className="p"><pre className="pre codeblock"><code>apiVersion: batch/v1{"\n"}kind: Job{"\n"}metadata:{"\n"}{"  "}name: katalon-job{"\n"}spec:{"\n"}{"  "}template:{"\n"}{"    "}spec:{"\n"}{"      "}containers:{"\n"}{"      "}- name: katalon{"\n"}{"        "}image: &lt;dockerhub-username&gt;/katalon-custom:latest{"\n"}{"        "}command:{"\n"}{"        "}- /bin/bash{"\n"}{"        "}- -c{"\n"}{"        "}args:{"\n"}{"        "}- |{"\n"}{"          "}echo "Starting Git Clone" &amp;&amp; \{"\n"}{"          "}git clone &lt;your-github-url&gt; /tmp/katalon_execute/project &amp;&amp; \{"\n"}{"          "}echo "Git Clone Completed" &amp;&amp; \{"\n"}{"          "}cd /tmp/katalon_execute &amp;&amp; \{"\n"}{"          "}katalonc.sh -browserType=Chrome -retry=0 -statusDelay=15 -testSuitePath="Test Suites/TS_RegressionTest" -apiKey=&lt;your-apikey&gt; --config -webui.autoUpdateDrivers=true -runMode=console -reportFolder=/tmp/katalon_execute/report -projectPath=/tmp/katalon_execute/project/test.prj -logLevel=DEBUG{"\n"}{"        "}resources:{"\n"}{"          "}limits:{"\n"}{"            "}cpu: 2{"\n"}{"            "}memory: 4Gi{"\n"}{"          "}requests:{"\n"}{"            "}cpu: 1{"\n"}{"            "}memory: 2Gi{"\n"}{"      "}restartPolicy: Never{"\n"}{"  "}backoffLimit: 4</code></pre></div><div className="note note note_note"><span className="note__title">Note:</span> The <code className="ph codeph">resources</code> section in the YAML file specifies the CPU and memory requests and limits for the job. Adjust these values based on the available resources in your OpenShift cluster and the requirements of your Katalon tests.</div></div></li><li className="li step stepexpand"><span className="ph cmd">Apply the YAML file using the following CLI command in the terminal:</span><div className="itemgroup info"><pre className="pre codeblock"><code>oc apply -f ~/katalon-job.yaml</code></pre>This command deploys the job configuration defined in the <code className="ph codeph">katalon-job.yaml</code> file to the OpenShift cluster.</div></li><li className="li step stepexpand"><span className="ph cmd">Get the list of pods.</span><div className="itemgroup info"><pre className="pre codeblock"><code>oc get pods</code></pre>This command will display a list of all pods along with their names and statuses.</div></li><li className="li step stepexpand"><span className="ph cmd">View the logs of the pod.</span><div className="itemgroup info"><pre className="pre codeblock"><code>oc logs -f &lt;pod-name&gt;</code></pre>Replace <code className="ph codeph">&lt;pod-name&gt;</code> with the actual name of the pod. This command will allow you to follow the logs live as the pod runs.</div></li></ol>

## <a id="task-3347" class="anchor_top_offset"/>View the Katalon job in the OpenShift web console

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">You can also view the Katalon job in the OpenShift web console by accessing the URL provided after starting CRC, for example, <code className="ph codeph">https://console-openshift-console.apps-crc.testing</code>.</p> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Log in using the provided credentials when starting CRC.</span><div className="itemgroup info"><img className="image" width={850} src={useBaseUrl("/a7d3bfa0-534f-49eb-8883-527b56e8b856/openshift-login.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Open <span className="ph uicontrol">Workloads</span> &gt; <span className="ph uicontrol">Jobs</span> and search your job's name.</span><div className="itemgroup info"><img className="image" width={850} src={useBaseUrl("/fbe064f2-1833-4ede-9609-2bcf18f7a07e/openshift-search-job-name.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Inside the <span className="ph uicontrol">Jobs</span>, click <span className="ph uicontrol">Pods</span> to see the list of your pods.</span><div className="itemgroup info"><img className="image" width={850} src={useBaseUrl("/51cce132-0d6a-4fd4-96ea-238dc054ee74/openshift-pods.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Inside the <span className="ph uicontrol">Pods</span>, you can see the <span className="ph uicontrol">Status</span> is <span className="ph uicontrol">Running</span>.</span><div className="itemgroup info"><img className="image" width={850} src={useBaseUrl("/1d6076b1-ca82-4613-9fe3-9c55a69ffc43/openshift-pods-status.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Click <span className="ph uicontrol">Logs</span> to view the progress of the job.</span><div className="itemgroup info"><img className="image" width={850} src={useBaseUrl("/58213db9-7a88-4922-b736-abc6278f851d/openshift-logs.png")} /></div></li></ol>
