<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">The <strong className="ph b">PDF Utility</strong> plugin provides 14 custom keywords that allow testers to work with PDF documents in various ways. You can extract and compare content, save pages as images, and perform other tasks within automated test cases.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="section prereq p"><ul className="ul"><li className="li"><p className="p"><a className="xref j-external-link" href="https://store.katalon.com/product/399/PDF-Utility" target="_blank">PDF Utility</a> plugin installed. For installation instructions, see <a className="xref" href="#">Install plugins online from the Katalon Store</a>.</p></li><li className="li"><p className="p">A sample project (optional). You can access our sample project on GitHub at <a className="xref j-external-link" href="https://github.com/katalon-studio/katalon-studio-pdf-keywords-plugin" target="_blank">katalon-studio/katalon-studio-pdf-keywords-plugin</a>. Clone it to follow along, or use your own project if you prefer.</p></li></ul></div>
