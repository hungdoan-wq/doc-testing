<div xmlns="http://www.w3.org/1999/xhtml" className="p">WireMock plays a crucial role in service virtualization by allowing users to easily mimic a production API's behavior. This capability is essential for various testing scenarios, including:<ul className="ul"><li className="li">Building test assets even when the production APIs are not ready or released.</li><li className="li">Reducing test flakiness by stabilizing interactions with third-party APIs.</li><li className="li">Simulating edge cases and faults to facilitate unhappy path testing.</li></ul>This guide demonstrates how to integrate Katalon Studio with WireMock Cloud to create and test mock versions of APIs. For those who prefer a visual walkthrough, a video version of this tutorial is also available <a className="xref j-external-link" href="https://www.youtube.com/watch?v=-m2A6wn7j9E" target="_blank">here</a>.</div>

## Requirements

<div xmlns="http://www.w3.org/1999/xhtml" className="p"><ul className="ul"><li className="li"><p className="p">A <a className="xref j-external-link" href="https://app.wiremock.cloud/" target="_blank">WireMock Cloud</a> account (free or paid plan).</p></li></ul></div>

## <a id="task-297" class="anchor_top_offset"/>Set up a mock API

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">You can create a mock API by configuring WireMock Cloud to proxy traffic to an existing API accessible over the internet and record requests as stubs.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Create your mock API</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Log in to your WireMock Cloud dashboard.</span></li><li className="li step stepexpand"><span className="ph cmd">In the home page, click <span className="ph uicontrol">Create new mock API</span>.</span><div className="itemgroup info"><img className="image" width={300} src={useBaseUrl("/280be331-cc1d-4057-80dd-b58e60111d1e/wiremock-create-api.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">Choose your API types.</span><div className="itemgroup info"><img className="image" width={300} src={useBaseUrl("/85e59dac-9bfe-49da-93d1-7438f8c14a60/wiremock-choose-api-types.png")} /><p className="p">In this example, we use the <span className="ph uicontrol">Blank</span> template.</p></div></li><li className="li step stepexpand"><span className="ph cmd">Enter your <span className="ph uicontrol">API name</span> and <span className="ph uicontrol">Custom hostname</span>. Then, click <span className="ph uicontrol">Save</span>.</span><div className="itemgroup info"><img className="image" width={300} src={useBaseUrl("/1a94a884-5e8d-4470-b487-7014d41559e0/wiremock-choose-api-names.png")} /></div></li></ol> 
<div xmlns="http://www.w3.org/1999/xhtml" className="li stepsection">Record and create a stub</div>
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps" start={5}><li className="li step stepexpand"><span className="ph cmd">On the <span className="ph uicontrol">Stubs</span> page, hit the <span className="ph uicontrol">Record</span> button.</span><div className="itemgroup info"><img className="image" width={300} src={useBaseUrl("/46f8057a-b1b6-4df6-8bfd-214c4fa584cd/wiremock-record-new-stub.png")} /></div><div className="itemgroup stepresult">The <span className="ph uicontrol">Stub Recorder</span> dialog appears.<p className="p"><img className="image" width={500} src={useBaseUrl("/345bc7f7-eb68-4fec-a2ff-d1f27bc08ab1/stub-recorder-dialog.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">In <span className="ph uicontrol">Target URL</span>, paste the URL of the API you wish to record from. Then, click <span className="ph uicontrol">Start</span>.</span><div className="itemgroup info">In this example, we use a hosted REST-API at <a className="xref j-external-link" href="https://reqres.in" target="_blank">reqres.in</a>.</div></li><li className="li step stepexpand"><span className="ph cmd">Make a request to your mock API by running this command (replace <code className="ph codeph">testapikatalon</code> with your subdomain name):</span><div className="itemgroup info"><div className="p"><pre className="pre codeblock"><code>curl -v https://testapikatalon.wiremockapi.cloud/json</code></pre></div><p className="p">This request will be proxied through WireMock Cloud, so that a <code className="ph codeph">GET</code> request will be made to <code className="ph codeph">https://reqres.in/api/json</code> and the result captured.</p><p className="p">After running the command, <code className="ph codeph">https://testapikatalon.wiremockapi.cloud/json</code> will become the URL of the mock API.</p></div></li><li className="li step stepexpand"><span className="ph cmd">Hit <span className="ph uicontrol">Stop</span>.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">Upon completing these steps with WireMock Cloud's traffic record function, you should see a new stub in the list:<p className="p"><img className="image" width={500} src={useBaseUrl("/a965d82f-2ca4-482a-b74f-c8193208bac7/wire-mock-new-recording-stub.png")} /></p><div className="note note note_note"><span className="note__title">Note:</span> In addition to creating a mock of an existing API, WireMock Cloud offers several methods to set up a mock API. ## <a id="task-7413" class="anchor_top_offset"/>Create a mock endpoint

<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">You can create a new stub within Katalon Studio without needing to use the WireMock Cloud user interface. Simply send a POST request with the desired data to set up the stub in WireMock Cloud.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Follow these steps to create a new stub using Katalon Studio:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Select <span className="ph uicontrol">File</span> &gt; <span className="ph uicontrol">New</span> &gt; <span className="ph uicontrol">Web Service Request</span>.</span></li><li className="li step stepexpand"><span className="ph cmd">In the displayed <span className="ph uicontrol">New Web Service Request</span> dialog, name the request, specify the request type as <span className="ph uicontrol">RESTful</span>, and enter the URL for managing stub mappings. Then, click <span className="ph uicontrol">OK</span>.</span><div className="itemgroup tutorialinfo">Here's how to get the URL:</div><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">Go to WireMock Cloud app's home screen, select your created mock API.</span></li><li className="li substep substepexpand"><span className="ph cmd">Choose <span className="ph uicontrol">Settings</span> on the left sidebar.</span></li><li className="li substep substepexpand"><span className="ph cmd">Scroll down to see the <span className="ph uicontrol">Usage examples</span> section.</span><div className="itemgroup info"><img className="image" width={500} src={useBaseUrl("/5ac7a3b8-f908-44ad-adef-92ee5e0a0752/wiremock-usage-examples.png")} /><p className="p">In this section, the URL for managing stub mappings is provided. In this example, the URL is <code className="ph codeph">https://testapikatalon.wiremockapi.cloud/__admin/mappings</code>.</p></div></li></ol></li><li className="li step stepexpand"><span className="ph cmd">Select <span className="ph uicontrol">POST</span> request.</span><div className="itemgroup info"><img className="image" width={200} src={useBaseUrl("/8e240f60-edc3-4861-89cc-7efbd8434d09/KS-post-request.png")} /></div></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">HTTP Header</span> section, add specific <span className="ph uicontrol">Name</span> and <span className="ph uicontrol">Value</span>  as shown below:</span><div className="itemgroup info"><img className="image" width={500} src={useBaseUrl("/da60ec47-b053-4c5f-b1f7-b7fbdfdac331/KS-post-request-header.png")} /><p className="p">You can find the <span className="ph uicontrol">Value</span> of the <span className="ph uicontrol">Authorization</span> in the <span className="ph uicontrol">Usage examples</span> section above.</p></div></li><li className="li step stepexpand"><span className="ph cmd">In the <span className="ph uicontrol">HTTP Body</span> section, choose <span className="ph uicontrol">text</span>, then input your stub mapping definition.</span><div className="itemgroup info">For example, the text <code className="ph codeph">{'{'} "request": {'{'}"url": "/hello-world" {'}'}, "response": {'{'} "body": "Hi!"{'}'}{'}'}</code> is a JSON object that defines a stub mapping. This JSON object specifies the request to be matched and the response to be returned by WireMock Cloud.<p className="p"><img className="image" width={500} src={useBaseUrl("/d2dcfa8a-7ce6-43b7-ac4f-34c4754fe211/KS-post-request-body.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">Hit the <span className="ph uicontrol">Test Request</span> button.</span><div className="itemgroup info"><img className="image" width={500} src={useBaseUrl("/8617b42b-b3cc-4b89-a53c-56adecbfd82b/KS-post-request-mock-api.png")} /></div><div className="itemgroup stepresult">The <span className="ph uicontrol">POST</span> request will create a mock endpoint in WireMock Cloud, allowing remote connection to the WireMock Cloud server from Katalon Studio.<p className="p"><img className="image" width={300} src={useBaseUrl("/c4de69fc-1d6d-4ef0-9057-924dd17669c6/KS-post-responses-from-mock-api.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">Follow from <strong className="ph b">step 5</strong> of <a className="xref" href="/katalon-studio/integrations/wiremock-integration#verify-the-mock-api-responses">Verify the mock API responses</a> to execute the test.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">Upon completing these steps, you will see the mock endpoint created in Katalon Studio is now available in WireMock Cloud:<p className="p"><img className="image" width={500} src={useBaseUrl("/b92b2563-38fb-4fba-a7cc-cac63eae1617/wiremock-new-stub.png")} /></p></section>
