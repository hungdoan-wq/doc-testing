<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">Katalon Studio (KS)</span> provides free, basic tools suitable for individuals' testing needs.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">Katalon Studio Enterprise (KSE)</span> is a more advanced business solution. If you want more test generation and execution, management, integration, and support capabilities of Katalon Studio, then get a per-user license. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">You can purchase an online KSE license from <a className="xref j-external-link" href="https://katalon.com/pricing" target="_blank">our pricing page</a>. For an <a className="xref" href="/katalon-studio/katalon-studio-enterprise-and-katalon-runtime-engine-license/online-vs.-offline-licenses">offline license</a> or a mix of both, contact sales at <code className="ph codeph">business@katalon.com</code>. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">To learn about difference between the <span className="ph">Katalon Studio Enterprise</span> and the <span className="ph">Katalon Studio (KS)</span>, see: <a className="xref" href="/katalon-studio/katalon-studio-enterprise-and-katalon-runtime-engine-license/katalon-studio-vs-katalon-studio-enterprise-features">Katalon Studio vs Katalon Studio Enterprise Features</a>.</p>
