---
title: View License Details
---

To view the details of your current license, open Katalon Studio. Go to:
 
 - macOS: **Katalon Studio > About Katalon Studio** 
 - Windows/Linux: **Help > About** 
 <img className="image" width="500px" src="/a1ccd360-326e-11ed-9930-0242fe3e4a3f/ks-view-license-details.png" alt="Katalon Studio Enterprise box that shows license information"/>
 
In the **About Katalon Studio Enterprise** dialog, you can view the version, edition and build of Katalon Studio, along with the expiration date of your Katalon license.
 
To learn more about Katalon licenses, see [Types of Licenses](/katalon-platform/administer/administration-and-licensing-alternate/manage-accounts/license-management/about-testops-license-types).
