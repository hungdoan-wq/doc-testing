## <a id="id_0__id" class="anchor_top_offset"/>Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p"><span className="ph">Katalon Studio</span> supports executing a single feature file with the <code className="ph codeph">runFeatureFileWithTags</code> function, using the following tag expressions:</p>
