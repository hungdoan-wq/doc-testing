## Troubleshooting: Unable to get value of <code xmlns="http://www.w3.org/1999/xhtml" className="ph codeph">content-desc</code>  attribute

<div xmlns="http://www.w3.org/1999/xhtml" className="p">When using the <code className="ph codeph">Mobile.getAttribute</code> keyword to retrieve the value of the <code className="ph codeph">content-desc</code> attribute for an element, you might encounter an issue where the returned value is empty. For example:<pre className="pre codeblock"><code>//*[@class = 'android.view.View' and @content-desc = 'Unable to Process Request' and @resource-id = '' and (@text = '' or . = '')]{"\n"}</code></pre></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">Cause</strong><p className="p">This issue happens because some mobile platforms use <code className="ph codeph">contentDescription</code> instead of <code className="ph codeph">content-desc</code> for the attribute name.</p></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="sectiondiv"><strong className="ph b">Remedy</strong><div className="p">Replace <code className="ph codeph">content-desc</code> with <code className="ph codeph">contentDescription</code> in your script. For example:<pre className="pre codeblock"><code>Mobile.getAttribute(yourObjectElement, 'contentDescription', 5, FailureHandling.OPTIONAL)</code></pre></div></div>
