## <a id="id_0__id" class="anchor_top_offset"/>Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Enter an encrypted text in an input field and clear the existing value of the input field. To encrypt a raw text, from the main menu, select <span className="ph uicontrol">Help</span> &gt; <span className="ph uicontrol">Encrypt Text</span>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">Mobile.setEncryptedText</code></p>
