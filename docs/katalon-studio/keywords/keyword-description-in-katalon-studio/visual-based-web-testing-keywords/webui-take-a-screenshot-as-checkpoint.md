## Description

                        
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Take a screenshot of the current viewport to send to TestOps Vision. The captured image will be saved in <code className="ph codeph">.png</code> format and stored in the <code className="ph codeph">keyes</code> folder inn the report folder.</p> 
            
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">takeScreenshotAsCheckpoint</code></p>
