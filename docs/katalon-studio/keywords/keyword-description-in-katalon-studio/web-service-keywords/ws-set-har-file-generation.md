## <a id="id_0__id_1" class="anchor_top_offset"/>Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Enable or disable HAR file generation either at the test case or test suite level.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Katalon Studio generates HAR files for each Web Service request by default. To learn how to access HAR files, see <a className="xref" href="/katalon-studio/test-reports/view-test-reports/view-and-customize-execution-log-in-katalon-studio#id_6">Extensive logs for Web Service testing</a>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">setHarFileGeneration</code></p>
