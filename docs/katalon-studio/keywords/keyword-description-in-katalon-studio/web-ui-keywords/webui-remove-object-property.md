## <a id="id_0__id_1" class="anchor_top_offset"/>Description 

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Remove existing property of test object. Use when test object has attributes changing in runtime. </p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">This keyword does not modify the object saved in Object Repository, instead, it creates another test object, modify and return this test object. Hence, users must use a variable to store the returned object.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">removeObjectProperty</code></p>
