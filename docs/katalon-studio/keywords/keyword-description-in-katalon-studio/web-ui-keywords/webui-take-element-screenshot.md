## <a id="id_0__id" class="anchor_top_offset"/>Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Take a screenshot of a specific web element. The captured image will be saved in <code className="ph codeph">.png</code> format.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">takeElementScreenshot</code></p>

The file name is <code className="ph codeph">logo.png</code> and stored in the report folder.
