## <a id="id_0__id" class="anchor_top_offset"/>Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p"> Verify if the options at the given indices are selected.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">verifyOptionSelectedByIndex</code></p>
