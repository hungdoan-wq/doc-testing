## Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Perform a set text action on the Web element that is found by using the locator value of the given Windows object. This action will append the given text on the element and clear the current text of the element if it exists.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">setEncryptedText</code></p>
