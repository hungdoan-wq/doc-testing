## Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Start Windows driver and starts the Windows application at the given absolute path. After the application starts, if WinAppDriver cannot detect the main application window correctly, Katalon Studio will use the given window title parameter to find the opened application to continue working.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">startApplicationWithTitle</code></p>
