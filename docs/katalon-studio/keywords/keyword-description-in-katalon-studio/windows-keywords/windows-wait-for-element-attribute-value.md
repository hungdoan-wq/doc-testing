## Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Wait until the given element has an attribute with the specified name and value within the given time in the second unit.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">waitForElementAttributeValue</code></p>
