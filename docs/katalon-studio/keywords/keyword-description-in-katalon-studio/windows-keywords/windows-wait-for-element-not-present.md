## Description

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Wait until the given element to not present (disappear) within the given time in the second unit.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">Keyword name: <code className="ph codeph">waitForElementNotPresent</code></p>
