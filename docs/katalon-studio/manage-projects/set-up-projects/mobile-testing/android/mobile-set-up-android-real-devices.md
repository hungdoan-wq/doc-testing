<p xmlns="http://www.w3.org/1999/xhtml" className="p">This article shows you how to set up real Android devices to test Android applications with <span className="ph">Katalon Studio</span>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">For mobile testing with Android Studio Emulator, refer to this document: <a className="xref" href="/katalon-studio/manage-projects/set-up-projects/mobile-testing/android/mobile-configure-android-emulator">[Mobile] Configure Android Studio (Emulator)</a>.</p></li></ul></div>

## <a id="task-7867" class="anchor_top_offset"/>1. Install Appium

<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Download and install the suitable version of Node.js for your system from the Node.js website: <a className="xref j-external-link" href="https://nodejs.org/en/download/" target="_blank">Downloads</a>.</span><div className="itemgroup info">Make sure you install Node.js into a location where you have full Read/Write permissions.</div></li><li className="li step stepexpand"><span className="ph cmd">Install Appium with the following commands in the Terminal:</span><div className="itemgroup info">       <ul className="ul"><li className="li">For <span className="ph">Katalon Studio</span> 9.1.0 onwards, install the latest Appium version:<pre className="pre codeblock"><code>npm install -g appium</code></pre></li><li className="li">For <span className="ph">Katalon Studio</span> before 9.1.0, install Appium 1.12.1+:<pre className="pre codeblock"><code>npm install -g appium@version</code></pre></li></ul>       <p className="p">Some emulators come with Appium installed. If you want to run an application on an emulator, check your emulator settings before installing Appium.</p>       <div className="note note note_note"><span className="note__title">Note:</span> <p className="p"><strong className="ph b">For Linux machine:</strong></p><ul className="ul"><li className="li">If you see an EACCES error with the Appium installation command, follow the instructions of npm documentation here: <a className="xref j-external-link" href="https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally" target="_blank">Resolving EACCES permissions errors when installing packages globally</a>.</li><li className="li">If you encounter an error where the Java <code className="ph codeph">jar</code> file can't be found, you might need to add the environment variable: <code className="ph codeph">KATALON_JAVA_HOME= &lt;JRE_location&gt;</code>. See related discussion on Ask Ubuntu: <a className="xref j-external-link" href="https://askubuntu.com/questions/175514/how-to-set-java-home-for-java?utm_medim=organic&utm_source=google_rich_qa&utm_campaign=google_rich_qa" target="_blank">How to set JAVA_HOME for Java?</a>           </li><li className="li">             <p className="p">Set the Appium directory manually in <span className="ph uicontrol">Katalon Studio Preferences</span>. The default directory should be <code className="ph codeph">/usr/lib/node_modules/appium/</code>.</p>           </li></ul></div>     </div></li></ol> 

## <a id="task-5963" class="anchor_top_offset"/>2. Set up the device

<section xmlns="http://www.w3.org/1999/xhtml" className="section context">To set up the device on your Windows/macOS/Linux machine, do as follows:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Go to <span className="ph uicontrol">Settings</span> &gt; <span className="ph uicontrol">Developer options</span> to turn on developer mode on your Android device.</span><ol type="a" className="ol substeps"><li className="li substep substepexpand"><span className="ph cmd">On a Windows machine, you also need to enable the following settings:</span><div className="itemgroup info"> <ul className="ul"><li className="li">USB debugging – Debug mode when USB is connected.</li><li className="li">Install via USB – Allow installing apps via USB.</li><li className="li">USB debugging (Security Setting) – Allow granting permissions and simulating input via USB debugging.</li></ul></div></li></ol></li><li className="li step stepexpand"><span className="ph cmd">Connect your Android phones to your computer via a USB cable and confirm to accept or trust the device.</span></li><li className="li step stepexpand"><span className="ph cmd">Install Android SDK.</span><div className="itemgroup info">Katalon Studio will automatically detect and ask you to install Android SDK if your current machine does not have it.</div></li></ol> 

## <a id="id_5" class="anchor_top_offset"/>3. Verify successful Android devices connection

<p xmlns="http://www.w3.org/1999/xhtml" className="p">After completing setting up your environment, to check whether Katalon successfully recognizes your Android devices, open a sample Android project in <span className="ph uicontrol">File</span> &gt; <span className="ph uicontrol">New Sample Project</span>.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" src={useBaseUrl("https://github.com/katalon-studio/docs-images/raw/master/katalon-studio/docs/mobile-on-macos/KS-Android-Open--Sample-project.png")} width={700} alt="Open Android sample project" /><br /><br /></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">On the main toolbar, open the dropdown list next to <span className="ph uicontrol">Run</span> and select the <span className="ph uicontrol">Android</span> device.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p"><img className="image" width={200} src={useBaseUrl("/13c3c680-9b15-11ee-b8c3-0242c7a41fd4/ks-toolbar-Android.png")} /></p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">You should see the name of your Android device in a pop-up dialog.</p>
