<p xmlns="http://www.w3.org/1999/xhtml" className="p">In Appium 2.x, one major change is the independence of drivers. This change separates tools and processes of building and using drivers for different platforms. With the ability to install and work with decoupled web drivers based on your application platform (iOS, Android, etc.), you can reduce your setup time and improve mobile testing performance in Katalon Studio.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">The following documentation provides guidance on how to configure and execute mobile tests with Appium 2.x, and more.</p> 

## Requirements

<div xmlns="http://www.w3.org/1999/xhtml" className="p"><ul className="ul"><li className="li">Katalon Studio version 9.1.0 and later versions.</li><li className="li"><a className="xref j-external-link" href="https://nodejs.org/en/" target="_blank">Node.js 14+</a>.</li><li className="li"><a className="xref j-external-link" href="https://www.npmjs.com/" target="_blank">Node Package Manager 8+ (NPM)</a>. This is usually bundled with Node.js, but you can upgrade independently.</li></ul></div>
<div xmlns="http://www.w3.org/1999/xhtml" className="note note note_note"><span className="note__title">Note:</span> <p className="p">We recommend downloading and installing Node.js from the official website instead of using package manager (e.g., <code className="ph codeph">brew</code> or <code className="ph codeph">apk</code>) to avoid issues.</p></div>

## <a id="task-5167" class="anchor_top_offset"/>Install Appium 2.x and execute mobile tests

<section>This section shows you how to install Appium 2x, install the required drivers for mobile execution in Katalon Studio, and execute tests using Appium 2.x.</section> 
<ol><li>Install Appium 2.x via NPM using the following command:<div><pre><code>npm i --location=global appium</code></pre></div></li><li><span>Installing Appium 2.0 only installs the Appium server, but not the drivers since all drivers have been isolated from the Appium server app. As such, install the Appium XCUITest Driver for iOS and Appium UiAutomator2 Driver for Android.</span><div><ul><li><p><strong>For iOS</strong>: The Appium XCUITest Driver, which is based on the Apple XCTest framework, is used for iOS native and web apps (via hybrid mode), and can only be used on macOS. To learn more about Appium XCUITest Driver, refer to the Appium repository on GitHub: <a href="https://github.com/appium/appium-xcuitest-driver" target="_blank">appium-xcuitest-driver</a>. </p><p className="p">Run the following command to install the latest version of Appium XCUITest driver (version 7.21.1):</p><div><pre><code>appium driver install xcuitest@7.21.1</code></pre><div><span>Note:</span> <ul><li><p>If you are using Appium 2.0 and Xcode 14 to test with physical iOS devices, you need to manually install WebDriverAgent. See the following article for more information: <a href="/katalon-studio/manage-projects/set-up-projects/mobile-testing/execute-mobile-tests-with-appium-2.x#build-webdriveragent-for-real-ios-devices-with-appium-20-and-xcode-14">Build WebDriverAgent for real iOS devices with Appium 2.0 and Xcode 14</a>.</p></li></ul></div></div></li><li><p><strong>For Android</strong>: The Appium UiAutomator2 Driver for Android native and web apps (via hybrid mode) is based on the Google UiAutomator framework. To learn more about Appium UiAutomator2 Driver, refer to the Appium repository on GitHub: <a href="https://github.com/appium/appium-uiautomator2-driver" target="_blank">appium-uiautomator2-driver</a>.</p><p className="p">Run the following command to install the recommended version of the Appium UiAutomator2 driver (version 3.7.0):</p><div className="p"><pre><code>appium driver install uiautomator2@3.7.0</code></pre></div></li></ul></div></li><li><span>If you have both Appium 1 and Appium 2 on your machine, make sure to specify the Appium version to execute your test with. To do so, go to <span><span>Preferences</span><abbr title="and then"> &gt; </abbr><span>Katalon</span><abbr title="and then"> &gt; </abbr><span>Mobile</span><abbr title="and then"> &gt; </abbr><span>Appium Directory</span></span> .<img width={600} src={useBaseUrl("/5c41fc80-8f2e-11ee-ab4f-0242c7a41fd4/ks-910-appium-directory.png")} alt="Specify Appium directory in Preferences" /></span><div>Click <span>Apply and Close</span>.</div></li><li><span>Execute your mobile test.</span></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">After you executed your test in Katalon Studio, switch to the <span className="ph uicontrol">Console</span> tab to check whether Katalon Studio detects the NodeJS location, starts Appium, and loads all drivers you installed as shown below:<p className="p"><img className="image" width={700} src={useBaseUrl("/10efd0c0-77a3-11ed-a602-0242cfbc79b5/ks-854-console.png")} /></p>In the <span className="ph uicontrol">Log Viewer</span>, the example below shows that Katalon Studio has successfully started the application with Appium version 2.x:<p className="p"><img className="image" width={700} src={useBaseUrl("/11552240-77a3-11ed-a602-0242cfbc79b5/ks-854-log-viewer.png")} /></p><p className="p">To learn more about execution logs in Katalon Studio, refer to the following document: <a className="xref" href="/katalon-studio/test-reports/view-test-reports/view-and-customize-execution-log-in-katalon-studio">View and customize execution log in <span className="ph">Katalon Studio</span></a>.</p><p className="p">For troubleshooting, refer to the following document: <a className="xref" href="/katalon-studio/troubleshooting/troubleshoot-mobile-automated-testing/unable-to-start-application-on-this-device-appium-directory-is-invalid">Unable to Start Application on this device: Appium directory is invalid</a>.</p></section>
