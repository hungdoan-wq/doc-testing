## <a id="concept-6099" class="anchor_top_offset"/>What is AWS Signature?

<p xmlns="http://www.w3.org/1999/xhtml" className="p">AWS Signature is the authorization workflow used for Amazon Web Services (AWS) requests. It employs a custom HTTP scheme based on a keyed-HMAC (Hash Message Authentication Code) for authentication.</p> 
<p xmlns="http://www.w3.org/1999/xhtml" className="p">To learn more about AWS Signature authentication, you can refer to AWS documentation: <a className="xref j-external-link" href="https://docs.aws.amazon.com/AmazonS3/latest/API/sig-v4-authenticating-requests.html" target="_blank">Authenticating Requests</a>.</p> 
<div xmlns="http://www.w3.org/1999/xhtml" className="p"><div className="note note note_note"><span className="note__title">Note:</span> <ul className="ul"><li className="li"><p className="p">Katalon Studio only supports AWS Signature version 4.</p></li></ul></div></div>
