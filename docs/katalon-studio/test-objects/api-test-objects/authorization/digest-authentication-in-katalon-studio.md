## <a id="concept-3491" class="anchor_top_offset"/>What is Digest authentication?

<p xmlns="http://www.w3.org/1999/xhtml" className="p">Digest authentication is an HTTP-based authentication protocol that enhances security by using MD5 cryptographic hashing and a nonce value to prevent replay attacks. Unlike Basic authentication, it transmits a hash of the username and password, ensuring that these credentials are not sent in plaintext over the network. While it secures the authentication credentials, the actual body of the HTTP message remains unencrypted unless Secure Sockets Layer (SSL) is used.</p>

## <a id="task-84" class="anchor_top_offset"/>Use Digest authentication in Katalon Studio
