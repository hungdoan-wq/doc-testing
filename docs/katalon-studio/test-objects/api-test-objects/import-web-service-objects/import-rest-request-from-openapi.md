<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc">OpenAPI Specification (OAS) is a definition file that describes an API or elements of an API. You can use an API definition file to import REST request into Katalon Studio.</p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section context">Your definition file should follow version 3.0 or 2.0 of the OpenAPI Specification. The format of the file can be in JSON or YAML. To import an API definition in OpenAPI Specification, do as follows:</section> 
<ol xmlns="http://www.w3.org/1999/xhtml" className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Create or open your API project.</span></li><li className="li step stepexpand"><span className="ph cmd">From the main toolbar, click the <span className="ph uicontrol">Import OpenAPI</span> icon.</span><div className="itemgroup info"><p className="p"><img className="image" width={500} src={useBaseUrl("/541da7d0-f24c-11ee-a73e-0242c7a41fd4/ks-940-click-import-OpenAPI.png")} /></p><p className="p">Alternatively, in the <span className="ph uicontrol">Tests Explorer</span> panel, right-click <span className="ph uicontrol">Object Repository</span> &gt; <span className="ph uicontrol">Import</span> &gt; <span className="ph uicontrol">From OpenAPI</span>.</p><p className="p"><img className="image" width={400} src={useBaseUrl("/541a7380-f24c-11ee-a73e-0242c7a41fd4/ks-940-import-openapi-menu.png")} /></p></div></li><li className="li step stepexpand"><span className="ph cmd">In the displayed <span className="ph uicontrol">Import REST request from OpenAPI/Swagger</span> dialog, enter a URL, or click <span className="ph uicontrol">Browse</span> to select a definition file.</span><div className="itemgroup info"><img className="image" width={500} src={useBaseUrl("/540eb3b0-f24c-11ee-a73e-0242c7a41fd4/ks-940-import-openapi-dialog.png")} /><div className="note attention note_attention"><span className="note__title">Attention:</span> <ul className="ul"><li className="li">No Raw text content in HTTP Body parsed from Swagger.</li><li className="li">No Authorization parsed from Swagger and OpenAPI 3.</li><li className="li">Variables and parameters must be adjusted manually.</li></ul></div></div></li></ol> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section result">Katalon Studio loads the file and generates RESTful requests into a folder accordingly.<p className="p"><img className="image" width={400} src={useBaseUrl("/6fc5c6c0-538d-11ed-a602-0242cfbc79b5/ks-object-repository.png")} /></p></section>
