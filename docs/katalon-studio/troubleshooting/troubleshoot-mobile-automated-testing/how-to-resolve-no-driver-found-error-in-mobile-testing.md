---
title: How to resolve "No Driver Found" error in mobile testing?
---


<p xmlns="http://www.w3.org/1999/xhtml" className="shortdesc"> </p> 
<section xmlns="http://www.w3.org/1999/xhtml" className="section condition"><div className="p">This error message shows when executing mobile tests: <pre className="pre codeblock"><code>com.kms.katalon.core.exception.StepFailedException: No driver found{"\n"}</code></pre></div></section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Make sure to set a correct directory in Appium Directory. In <span className="ph">Katalon Studio</span>, navigate to <span className="ph menucascade"><span className="ph uicontrol">Preferences</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Katalon</span><abbr title="and then"> &gt; </abbr><span className="ph uicontrol">Mobile</span></span>.</span><div className="itemgroup info"><p className="p">For MacOS, the Appium Directory is: <code className="ph codeph">usr/local/lib/node_modules/appium</code></p><p className="p">For Windows, the Appium Directory is:  <code className="ph codeph">C:\npm\node_modules\appium</code></p></div></li><li className="li step stepexpand"><span className="ph cmd"> Make sure  you were using the <span className="ph uicontrol">Mobile.startApplication</span> function in your test or test suite as the first step. If the application hasn't started, you might see that error message.</span></li><li className="li step stepexpand"><span className="ph cmd">If you're using a test suite, do not start and stop the application between tests, instead start it once at the beginning of the suite and shut it down at the end. Repeated starting and stopping of the application can put the driver in a bad state.</span></li><li className="li step stepexpand"><span className="ph cmd">Before running a test or test suite, check your running system processes for Appium. Sometimes these processes don't quit completely and can interfere with future  tests run.</span></li></ol></section></div>
