title: Set proxy certificate when connecting to remote devices
---

<section xmlns="http://www.w3.org/1999/xhtml" className="section condition"><div className="p">When spying, recording, or executing mobile tests with remote devices through a proxy, you may encounter the issue where Katalon Studio cannot create remote session:<pre className="pre codeblock"><code>java.util.concurrent.ExecutionException: org.openqa.selenium.SessionNotCreatedException: {"\n"}Unable to create a new remote session. {"\n"}Original error: PKIX path building failed: sun.security.provider.certpath.SunCertPathBuilderException: {"\n"}unable to find valid certification path to requested target</code></pre></div></section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">When working behind a proxy, Katalon Studio requires a proxy certificate  to connect to remote devices. This proxy certificate should be exported by your proxy server in  <code className="ph codeph">.cer</code> or <code className="ph codeph">.crt</code> format.</p><p className="p">Follow these steps to add the proxy certificate to Katalon Studio:</p></section><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Open the JRE folder of Katalon Studio in your command prompt.</span><div className="itemgroup info"><p className="p">On macOS, JRE is located at: <code className="ph codeph">&lt;Katalon Studio folder&gt;/Contents/Eclipse/jre/bin</code>.</p><img className="image" width={500} src={useBaseUrl("/c5e66b5b-c099-41b6-a75a-433de7427d66/KS_JRE_bin_path.png")} alt="Katalon Studio JRE path" /></div></li><li className="li step stepexpand"><span className="ph cmd">Use <code className="ph codeph">keytool</code> utility to add the certificate.</span><div className="itemgroup info"><pre className="pre codeblock"><code>keytool -importcert -alias &lt;expectedName&gt; -keystore &lt;KS folder&gt;/jre/lib/security/cacerts -file &lt;path to certificate file with .cer/crt extension exported by the proxy server&gt;</code></pre><img className="image" width={700} src={useBaseUrl("/116ca887-f5ef-458d-adcb-8312657f7a58/KS_keytool_add_cert.png")} alt="keytool -importcert command" /><p className="p">If you're asked for a password, usually the default password is <code className="ph codeph">changeit</code>.</p></div><div className="itemgroup stepresult">Katalon Studio will use the imported certificate to connect to remote devices through the proxy.</div></li></ol></section></div>
