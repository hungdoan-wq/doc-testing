title: Unable to execute tests with iOS on macOS Ventura and XCode 14.x

<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">macOS Ventura no longer supports older Xcode versions. To test from it, you must have Xcode 14.x. However, there's an issue when using Xcode 14.x with Appium 1.x due to the outdated built-in XCUITest driver. To use Xcode 14.x with Appium 1.x, you need to update the XCUITest driver to a newer version.</p></section><section className="section remedy"><ol className="ol steps"><li className="li step stepexpand"><span className="ph cmd">Install Appium XCUITest driver version 4.32.24 or newer:</span><div className="itemgroup info"><pre className="pre codeblock"><code>npm install appium-xcuitest-driver@4.32.24</code></pre></div></li></ol><div className="li stepsection"><strong className="ph b">Update code signing:</strong></div><ol className="ol steps" start={2}><li className="li step stepexpand"><span className="ph cmd">Navigate to <code className="ph codeph">node_modules/appium-webdriveragent</code> and open <code className="ph codeph">WebDriverAgent.xcodeproj</code> file in Xcode with the following command:</span><div className="itemgroup info"><pre className="pre codeblock"><code>cd &lt;node_modules/appium-webdriveragent&gt;{"\n"}open WebDriverAgent.xcodeproj</code></pre></div></li><li className="li step stepexpand"><span className="ph cmd">After opening <code className="ph codeph">WebDriverAgent.xcodeproj</code> file in Xcode, do as follows:</span><ol type="a" className="ol substeps"><li className="li substep"><span className="ph cmd">Uncheck <span className="ph uicontrol">Automatically manage signing</span>.</span></li><li className="li substep"><span className="ph cmd">Select <span className="ph uicontrol">Target</span> &gt; <span className="ph uicontrol">WebDriverAgentRunner</span>.</span></li><li className="li substep"><span className="ph cmd">Select <span className="ph uicontrol">Signing &amp; Capabilities</span>.</span></li><li className="li substep"><span className="ph cmd">Select <span className="ph uicontrol">Provisioning Profile</span>. Make sure you have installed Certificate &amp; Wildcard Provisioning Profile on your machine.</span></li><li className="li substep"><span className="ph cmd">Select <span className="ph uicontrol">Product</span> &gt; <span className="ph uicontrol">Test</span>.</span></li></ol></li></ol></section></div>
