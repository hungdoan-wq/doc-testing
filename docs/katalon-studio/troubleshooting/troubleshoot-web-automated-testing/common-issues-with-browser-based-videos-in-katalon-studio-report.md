<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">There are no physical video files in the folder, or it only shows the <code className="ph codeph">.srt</code> file.</p><p className="p">The issue might happen due to different decimal separators in different languages which leads to an invalid duration format for each screen frame. <div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><p className="p">There are no videos generated.
