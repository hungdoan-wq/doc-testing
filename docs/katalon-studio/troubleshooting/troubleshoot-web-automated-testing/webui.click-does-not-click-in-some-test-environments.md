---
title: WebUI.click() does not click in some test environments
---


<section xmlns="http://www.w3.org/1999/xhtml" className="section condition"><p className="p"><code className="ph codeph">WebUI.click()</code> keyword is sometimes does not click when executing  tests in certain environments, there is no error message.</p></section> 
<div xmlns="http://www.w3.org/1999/xhtml" className="bodydiv troubleSolution"><section className="section cause"><div className="p">Selenium WebDriver checks two preconditions when we click a web element:<ul className="ul"><li className="li"><p className="p">The element must be visible.</p></li><li className="li"><p className="p">It must have a height and width greater than 0px.</p></li></ul>In the case where the preconditions are not satisfied, you will get exceptions stating the element is not clickable or interactable. But when you use JavaScript click, JavaScript does not check these preconditions and instead go on  triggering a click event on the element, even though the element may not be visible. Therefore, we should choose WebDriver and use JavaScript sparingly and only when direct methods of WebDriver doesn't work.</div></section><section className="section remedy"><div className="li step p"><span className="ph cmd">We suggest using the <a className="xref j-external-link" href="https://docs.katalon.com/katalon-studio/docs/webui-execute-javascript.html#description-" target="_blank">JavascriptExecutor</a> like the sample below instead of using the <code className="ph codeph">WebUI.click()</code> keyword: </span><div className="itemgroup info"><pre className="pre codeblock"><code>import com.kms.katalon.core.webui.common.WebUiCommonHelper as WebUiCommonHelper{"\n"}import org.openqa.selenium.WebElement as WebElement{"\n"}WebElement element = WebUiCommonHelper.findWebElement(findTestObject('your/object'),30) WebUI.executeJavaScript("arguments[0].click()", Arrays.asList(element))</code></pre></div></div></section></div>
