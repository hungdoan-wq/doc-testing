# Quick Guide for Users

This guide is meant for:
- Product Owner
- QA Manager
- Automation Engineers
- Manual Testers

Features you should care about

## Product Owner

| Key Feature | Purpose |
| -- | -- |
| Requirement Coverage Report | Identify coverage percentage, gap analysis, and risks |
| Requirement Traceability Report | Track requirement lifecycle from creation to validation |
| Release Health Dashboard | See `Go/Caution/Stop` signals for release decisions<br/>Compare release quality and trends between releases |
| Quality Gates Configuration | Customizable thresholds for pass rate, coverage, and defect density |
| Analytics & Trends Dashboard | View pass rate trends, failure rate patterns, and quality trajectory
| Defect Trend Analysis Report | View defect density, distribution, and resolution rates |
| AI Executive Briefing | Generate 3-part summaries (Quality Snapshot, Risk Assessment, Recommendations) for a release |
| External Report Sharing | Share secure, time-limited links for external stakeholders with customizable expiration |
