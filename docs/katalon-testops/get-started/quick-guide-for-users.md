# Quick Guide for Users

This guide is meant for:
- Product Owner
- QA Manager
- Automation Specialists
- Manual Testers


Docs you should care about:

- Product owner:
  - Release Health

- QA Manager:
  - Create releases, requirements & assign test cases to teammates.
  - All reports & dashboards.


- Manual Testers:
  - view requirements, releases and assignments from QA
  - manual testing
  - Execute & schedule manual tests
  - View test results
  - Reports n dashboards to care about:
    - 3 dashboards
    - Test Results Analysis Report
    - Test Failures Analysis Report
    - Defects Status Analysis Report
    - Test Case Health Analysis Report (Flakiness part)
    - Test Case Publishing Activity Analysis Report 
    - flakiness doc

- Automation Specialists:
  - view requirements, releases and assignments from QA
  - manual testing UI
  - Create automated tests from manual testing
  - Execute & schedule automated tests
  - View test results
  - Reports n dashboards to care about:
    - 3 dashboards
    - Test Results Analysis Report
    - Test Failures Analysis Report
    - Common Automation Errors Report
    - Defects Status Analysis Report
    - Test Case Health Analysis Report (Flakiness part)
    - Test Case Publishing Activity Analysis Report 
    - flakiness doc
